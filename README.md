# OMCP - Orbital Mission Control Platform

Dashboard web de controle de missao orbital, desenvolvido como Global Solution da FIAP. A interface e uma single page application escrita em HTML, CSS e JavaScript puros, sem dependencias externas, concentrada no arquivo `index.html`.

## Telas

O painel e dividido em dashboard operacional (com linha do tempo e fila critica), telemetria de sensores, alertas criticos, analise preditiva com recomendacao ativa, mapa orbital com enlaces e ativos, comandos e comunicacao (envio de novo comando e canal de comunicacao) e uma area de modulos, auditoria e relatorios.

## Tecnologias

HTML5, CSS3 com variaveis, grid e flexbox, e JavaScript sem frameworks.

## Como executar

Nao ha build nem dependencias: basta abrir o arquivo `index.html` no navegador, ou servir a pasta com qualquer servidor estatico, por exemplo `npx serve .`.
